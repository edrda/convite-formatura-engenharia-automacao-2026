# 🎓 Graduation Landing Page — FURG Automation Engineering

Landing page developed as a digital invitation for the graduation ceremony of the 13ª Turma de Engenharia de Automação da FURG, focusing on emotion, storytelling, and interactive experience.

---

# 🇧🇷 PT-BR

### ✨ Sobre o projeto

Esta landing page foi criada como um convite digital para a solenidade de formatura, destacando:

- Apresentação dos formandos
- Seção de homenagens
- Informações do evento
- Botão de confirmação de presença
- Integração com calendário
- Experiência visual interativa com animações leves

O objetivo principal é proporcionar uma experiência emocional, moderna e responsiva.

### 🛠️ Tecnologias

- Vue 3 + TypeScript
- Vite
- CSS Scoped
- Composables para animações (Intersection Observer)
- Assets otimizados (WebP)

### 📱 Responsividade

A interface foi projetada com abordagem mobile-first, garantindo:

- Interações com hover no desktop
- Animações autoplay no mobile
- Performance e carregamento leve

### 🎯 Funcionalidades

- Grid de formandos com fotos
- Cards animados (hover + autoplay)
- Seções com fade + slide reveal
- Botão “Marcar na agenda” (arquivo ICS)
- Estrutura componentizada

### 🚀 Como rodar o projeto
```
# instalar dependências
npm install

# rodar ambiente local
npm run dev

# build produção
npm run build

# preview build
npm run preview
```

### 📂 Estrutura resumida
```
src/
 ├─ assets/
 ├─ components/
 │   ├─ ui/
 │   └─ sections/
 ├─ composables/
 ├─ styles/
 └─ views/
```

### ❤️ Objetivo de UX

- O projeto prioriza:
- Emoção e narrativa
- Clareza das informações
- Interação leve
- Performance
- Responsividade

## 🇺🇸 EN

### ✨ About the project
This landing page was created as a digital invitation for the graduation ceremony of the 13th Automation Engineering class at FURG, focusing on emotion, storytelling, and interactive experience.

Key highlights:

- Graduates presentation
- Tribute section
- Event information
- RSVP confirmation button
- Calendar integration
- Lightweight animations
The main goal is to deliver a modern, emotional, and responsive experience.

### 🛠️ Tech stack

- Vue 3 + TypeScript
- Vite
- Scoped CSS
- Animation composables (Intersection Observer)
- Optimized assets (WebP)

### 📱 Responsiveness

The UI follows a mobile-first approach, providing:

- Hover interactions on desktop
- Autoplay animations on mobile
- Lightweight performance


### 🎯 Features

- Graduates photo grid
- Animated cards (hover + autoplay)
- Fade + slide section reveal
- “Add to calendar” button (ICS file)
- Component-driven architecture

### 🚀 Getting started
```
# install dependencies
npm install
```
